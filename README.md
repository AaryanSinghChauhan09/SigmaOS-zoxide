# SigmaOS-zoxide

SigmaOS zoxide component inspired by Linux Mint / Omarchy / Arch Linux.

Part of the SigmaOS modular operating-system ecosystem — one repository per
component, inspired by Arch Linux, Linux Mint, and Omarchy layouts.

## Principles

Single responsibility, component isolation, fail-fast, secure defaults,
memory-safe Rust, deterministic tests, stable APIs.

## Build & Test

```sh
cargo build
cargo test
```
